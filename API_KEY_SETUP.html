OCI API 密钥：一次性授权

脚本通过 Oracle 官方 SDK 工作，需要一组 API 签名密钥。它不能使用网页密码，也不需要你的银行卡信息。

安全提示：私钥只保存在这台 Mac 的 ~/.oci/oci_api_key.pem，不要把私钥内容粘贴到聊天、网页或发给任何人。

第一步：进入 API 密钥页面

  1. 回到已经登录的 OCI 控制台。
  2. 点击右上角头像。
  3. 点击“我的概要信息”或“用户设置”。
  4. 在左侧“资源”区域点击“API 密钥”。
  5. 点击“添加 API 密钥”。

第二步：生成密钥

  1. 选择“生成 API 密钥对”。
  2. 点击“下载私钥”，保存得到的 .pem 文件。
  3. 可同时下载公钥作为备份，但启动器不需要公钥文件。
  4. 点击对话框底部的“添加”。这是实际授权动作。

第三步：下载配置

  1. 添加完成后会出现“配置文件预览”。
  2. 点击“下载配置文件”。若页面只有复制按钮，可把完整内容粘贴到 TextEdit；纯文本或 RTF 都可以，安装器会自动识别。
  3. 配置应包含 [DEFAULT]、user、fingerprint、tenancy 和 region。

第四步：交给启动器安装

  1. 回到启动器的终端窗口并按回车。
  2. 第一个文件选择框选择刚下载的 OCI 配置文件。
  3. 第二个文件选择框选择刚下载的 PEM 私钥。
  4. 启动器将修正私钥路径并设置仅当前用户可读权限。

完成后以后不需要重复添加 API 密钥，除非你主动在 OCI 控制台删除或轮换它。
